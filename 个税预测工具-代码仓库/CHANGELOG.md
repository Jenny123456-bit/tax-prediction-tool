# 变更记录

格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [1.0.0] - 2026-10-27

首个正式版本。纯前端静态实现，已部署上线。

### 新增

**计税引擎**
- 综合所得七级超额累进税率表，基本减除费用 5000 元/月
- 全年一次性奖金单独计税（按月换算定档、按全额计税）与并入综合所得两种口径
- 年终奖计税方式自动择优，输出两方案差额
- 累计预扣法逐月模拟（12 个月），输出逐月预扣税额与到手金额
- 年度汇算差额推算（仅汇算扣除项导致的退税 / 补税）
- 六个「多发少得」盲区区间检测，上界由解方程求得而非硬编码

**扣除体系**
- 6 项专项附加扣除：子女教育、3 岁以下婴幼儿照护、继续教育、住房贷款利息、住房租金、赡养老人
- 其他扣除：个人养老金（≤12000/年）、商业健康险（≤2400/年）
- 处置口径区分：按月申报项进月度预扣，大病医疗与职业资格证书为年度汇算项

**诊断能力**
- 12 条扣除缺口规则，按「风险 / 重点 / 提示 / 科普」分级、按可节税额排序
- 节税额采用精确期权衡 `tax(T) − tax(T − d)`，跨档时不失真
- 跨档临界点提示：告知还差多少扣除额即可降档
- 已自动优化项（年终奖择优）标记为 "已优化"，不重复计入汇总

**界面**
- 一屏输入、一屏结果的响应式双栏布局（≥1120px 双栏，<720px 移动端）
- 主指标卡、税率档刻度条、年终奖方案对比、月度到手堆叠柱图、收入→扣除→应税结构条、测算明细表
- 一键复制测算明细、URL 编码分享方案、年度切换、参数重置

**AI 助手**
- 内置本地规则引擎，8 类意图识别，回答自动带入当前测算数字
- 支持任意 OpenAI 兼容接口，SSE 流式输出，4 类错误归因与本地兜底
- 配置项存于 localStorage，提供连接测试与清除
- 深链：`?chat=1` 打开助手，`?chat=1&q=问题` 预置提问

**工程**
- 零依赖、零构建，可直接双击 `index.html` 运行
- 33 条自动化测试（引擎单测 / 验收用例 / 静态契约），通过 GitHub Actions 在 Node 18/20/22 上验证
- 零依赖静态服务器脚本、CI 配置、部署文档

### 已知限制
- 未覆盖股权激励单独计税、企业年金、解除劳动关系一次性补偿、外籍人员八项补贴
- 社保缴费基数未做当地上下限校验
- 其他综合所得按统一 80% 口径录入（稿酬实际按 56% 计入收入额）
- 月度模拟假设月薪 12 个月等额发放
