# 个税预测 · Tax Forecast

> 输入工资、年终奖、公积金与专项附加扣除，一键预测全年个人所得税，并诊断出你还没用足的扣除项。

纯前端静态站点：**零后端、零构建、零运行时依赖**。双击 `index.html` 就能用，断网也能算。

---

## 为什么做这个

个人所得税是「累计预扣预缴 + 年度汇算清缴」两层结构，普通人在三件事上长期吃亏：

| 痛点 | 表现 | 后果 |
| --- | --- | --- |
| 看不懂工资条 | 下半年到手逐月变少 | 误以为公司少发，实际是累计所得升档 |
| 算不清年终奖 | 单独计税 / 并入综合，没人替你算 | 选错一次，多缴几千到几万 |
| 用不足扣除项 | 6 项专项附加扣除漏报 | 每年白交几百到几千元 |

这个工具把三件事一次解决：**算得准、说得清、还能告诉你少交多少**。

## 功能

### 1. 全年个税测算
- 综合所得七级超额累进税率，基本减除费用 5000 元/月
- 工资薪金 + 全年一次性奖金 + 劳务报酬等其他综合所得
- 五险一金按「缴费基数 × 个人费率」自动计算，公积金比例 5%–12% 可调
- 6 项专项附加扣除 + 个人养老金、商业健康险

### 2. 年终奖计税自动择优
并排计算「单独计税」与「并入综合所得」，自动取税额较小者，并告诉你差多少钱。该选择每年汇算时可自行切换。

### 3. 「多发少得」盲区预警
年终奖落在下列区间时红色告警，并给出建议发放额：

| 盲区下限 | 盲区上界 |
| --- | --- |
| 36,000 | 38,566.67 |
| 144,000 | 160,500.00 |
| 300,000 | 318,333.33 |
| 420,000 | 447,500.00 |
| 660,000 | 706,538.46 |
| 960,000 | 1,120,000.00 |

### 4. 累计预扣逐月模拟
按累计预扣法还原 12 个月的预扣税额，画出月度到手曲线——这能直接解释「为什么下半年到手变少了」。并据此推算年度汇算的退税 / 补税金额。

### 5. 扣除缺口诊断
12 条规则实时扫描，按「预计可节税额」从高到低排序：未申报的专项附加、公积金是否顶格、个人养老金是否用满、距降档还差多少扣除额、年终奖是否踩盲区……

### 6. AI 助手浮窗
- 默认**本地知识库模式**，无需任何配置即可提问，回答带上你当前的全部测算数字
- 可在设置里接入任意 **OpenAI 兼容**接口（DeepSeek / 通义千问 / Kimi / OpenAI），支持流式输出
- API Key 只存在浏览器 localStorage，不上传任何服务器

### 7. 分享与导出
全部入参编码进 URL（`#s=...`），发给同事打开即还原同一套测算；结果明细可一键复制为纯文本。

## 快速开始

### 方式一：直接打开（最快）
双击 **`index-standalone.html`** 即可。CSS 与 JS 已全部内联，**不依赖 `assets/` 目录**，从压缩包里直接打开、单独拷给他人、放任意目录都不会丢样式。

> 本交付包以**单文件版**为入口，因此目录里没有 `index.html`。`assets/` 下仍是完整的模块化源码（`tax-engine.js` / `app.js` / `chat.js` / `style.css`），便于阅读与二次开发；如需模块化入口，从 git 历史取回即可：
> ```bash
> git show 39716e0:个税预测工具/index.html > index.html
> ```
> 两个入口的行为完全一致（已验证渲染像素差异 0.0000%）。

### 方式二：本地服务器（推荐，避免个别浏览器的 file:// 限制）
```bash
node scripts/serve.js          # 默认 http://127.0.0.1:8080
node scripts/serve.js 8888     # 指定端口
```
或
```bash
npm run serve
```
也可以用任意静态服务器，例如：
```bash
python -m http.server 8080
npx serve .
```

### 方式三：部署到公网
见 [DEPLOY.md](DEPLOY.md)（含 CloudStudio / Nginx / GitHub Pages / Vercel 四种方式与部署后自检清单）。

### 引擎单测的运行方式

`tax-engine.js` 是挂载到 `window` 上的 IIFE，本身不依赖浏览器。测试用 Node `vm` 模块把它加载进隔离沙箱：

```js
const sandbox = { window: {} };
vm.createContext(sandbox);
vm.runInContext(code, sandbox, { filename: 'tax-engine.js' });
const E = sandbox.window.TaxEngine;
```

因此在 Node 里可以直接调用 `E.compute(params)` 做数值断言，无需 jsdom 之类的浏览器模拟。

## AI 助手接入

1. 点击右下角气泡打开助手 → 右上角齿轮
2. 选择服务商（一键填充）或手动填写：
   - 接口地址：`https://api.deepseek.com/v1`
   - 模型：`deepseek-chat`
   - API Key：`sk-...`
3. 点「测试连接」→「保存并启用」

> **注意**：浏览器直连接口要求服务端允许 CORS。DeepSeek、通义千问（compatible-mode）通常可直接调用；若遇到跨域失败，可自建一个转发服务，或继续使用本地知识库模式（功能完整，只是回答不如大模型灵活）。

请求体为标准 Chat Completions：`{ model, messages, temperature, stream: true }`，按 SSE 逐块解析。系统提示词会自动注入当前测算快照，并约束回答必须结合具体数字、标注政策依据、拒绝任何违法筹划建议。

## 隐私与安全

| 项 | 说明 |
| --- | --- |
| 收入数据 | 只在浏览器内存中计算，**不上传任何服务器**，无埋点、无追踪 |
| 分享链接 | 参数编码在 URL hash 中，不会随请求发送到服务器 |
| API Key | 仅存 `localStorage`（键名 `taxai.cfg.v1`），从不写入 URL、不随分享链接外泄 |
| AI 内容边界 | 系统提示词约束只讨论合法合规的税前扣除与计税方式选择，明确拒绝虚开发票、虚假申报等建议 |
| 离线可用 | 不加载任何 CDN，除 AI 助手外全部功能断网可用 |

详细评估见 [docs/安全自评.pdf](docs/安全自评.pdf)。

1. 《中华人民共和国个人所得税法》及其实施条例
2. 《个人所得税专项附加扣除暂行办法》（国发〔2018〕41 号）
3. 《国务院关于提高个人所得税有关专项附加扣除标准的通知》（国发〔2023〕13 号）
4. 《财政部 税务总局关于延续实施全年一次性奖金等个人所得税优惠政策的公告》（2023 年第 30 号）——单独计税执行至 2027 年 12 月 31 日
5. 《财政部 税务总局关于个人养老金有关个人所得税政策的公告》（2022 年第 34 号）

## 已知限制

- 未覆盖股权激励单独计税、企业年金、解除劳动关系一次性补偿、外籍人员八项补贴等特殊场景
- 社保缴费基数未做当地上下限校验
- 其他综合所得按统一 80% 口径录入（稿酬实际为 56%）
- 月度模拟假设月薪 12 个月等额发放，不含中途调薪或补发

> 本工具结果用于收入规划参考，不构成税务意见。实际应缴税额以扣缴义务人申报及税务机关年度汇算结果为准。
